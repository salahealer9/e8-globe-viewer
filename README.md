# E8 Alignment Viewer

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21419573.svg)](https://doi.org/10.5281/zenodo.21419573)

Interactive 3D globe viewer for the v4.0 pre-registered confirmatory phase of the
E8 lattice alignment investigation: does an optimally oriented projection of the
E8 root system's edge network align with a fixed catalog of 157 sites more
closely than search-optimised random controls?

## What it shows

- The supported E8 edge network (edges within 0.10° of ≥ 1 site) for each
  projection seed, rendered as great-circle arcs.
- The 157 catalog sites, colored by distance to the nearest E8 edge of the full
  6720-edge grid (**display bins only — not significance thresholds**).
- Per seed: the search-aware null distribution (1000 best-of-search trials) with
  the real RMS marked, plus p-value, z, Cohen's d, and BH-FDR status.
- Shared edges ("ley lines") passing near 2+ sites, with the site pairs named.
  Edges are colored by support tier: gold (1 site), platinum (2 sites), rose
  (3+ sites).

## Interactions

- Click a site → name label on the globe + distance readout in the panel.
- Click a shared edge → the sites it connects.
- `←` / `→` cycle through seeds; the seed selector groups by BH status.
- The URL hash tracks the current seed (`#seed788`) — links open directly on
  that view.
- "Fly to anchor" centres the camera on the seed's locked orientation point;
  "Light basemap" switches Natural Earth ↔ OpenStreetMap tiles.
- Each seed's panel shows the null histogram with a plain-language line —
  "k of 1000 search-optimised random rotations matched or beat the real RMS" —
  derived from the raw trial values (it reproduces the Monte-Carlo
  p = (k+1)/(n+1) exactly).

## The statistical claim, precisely

- The primary statistic is the **search-aware best-of-search RMS null**: each of
  1000 null trials gets the same orientation search the real catalog got.
- **BH-FDR at q = 0.05 was applied to the pre-registered 12-seed elite family**;
  10 of 12 survive. Seeds 1649 and 354 are not significant (uncorrected
  p = 0.054 and 0.059).
- **0 of 6 pre-registered control seeds are significant** (expected under null).
- No individual distance band (quantile threshold) is the claim; the signal is
  the family-level RMS result.
- **The signal is statistically robust; the mechanism is unknown. These are
  different claims.**

## Running

Any static server from this directory:

```
python -m http.server
# open http://localhost:8000
```

(Opening `index.html` directly via `file://` will not work — browsers block
`fetch()` of local data files.)

No API keys or tokens are required: imagery is CesiumJS's bundled Natural
Earth II.

## Data provenance

All files in `data/` are generated by `export_viewer_bundle.py` in the private
`earthgrid-research` engine repository — nothing in this viewer is hand-edited.
`data/manifest.json` embeds the engine commit hash, catalog SHA-256, generation
timestamp, and export parameters. The per-seed statistics are parsed directly
from the engine's 1000-trial KS/best-of-search result files; the viewer contains
no hardcoded numbers.
